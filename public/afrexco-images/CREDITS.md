## Note on resolution

`download-images.sh` pulls 2400px-wide JPEGs, which is right for a web build.
For print or large-format use, set `WIDTH=6000` or download the originals from
the source links above — several are 6000px or larger, and the aerial
(`02-about-aerial-grounds.jpg`) is 8192px.
